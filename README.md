# MLMCreator
MLMCreator is a user-friendly, modular machine learning web application built with Streamlit that enables users to upload datasets, preprocess data, train models, and evaluate results — all through an interactive interface. The app supports tabular, image, and text data workflows and provides advanced analytics, visualizations, and model management features.

🚀 Features
📁 CSV upload with session persistence

🔍 Smart preprocessing for tabular, image, and text data

⚙️ Model selection and training (classification & regression for tabular, deep learning for image/text)

📊 Evaluation with metrics and rich visualizations

💾 Model saving with metadata tracking

🔐 User login and session management

🧾 Notebook-style step-by-step UI

🗃️ PostgreSQL integration for dataset and model storage

🛠️ Technologies Used
🧱 Frontend
Streamlit – Interactive web UI

Plotly & Matplotlib – For rich visualizations

bcrypt – Secure password hashing

🧠 Backend
Python – Core logic, data processing, and ML

scikit-learn, PyTorch – Model training and evaluation

pandas, NumPy – Data handling

🗄️ Database
PostgreSQL – Stores user info, dataset metadata, and model metrics

🔧 Development Tools
Visual Studio Code

Jupyter Notebook (for model prototyping)
